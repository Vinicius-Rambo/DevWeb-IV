## Desenvolvimento Web IV

**Componente** Curricular: Desenvolvimento Web IV  
**Semestre**: Optativo  
**Carga** **horária**: 80h (67h relógio)  
**Professor**: Itamar Pena Nieradka

---
## Objetivo

Apresentar conceitos e características de **aplicações web e distribuídas** com enfoque no uso de APIs e técnicas de serialização de dados.

A disciplina busca desenvolver a capacidade de:

- Expor e consumir serviços no back-end e front-end
- Integrar aplicações com APIs externas e consumir serviços 
- Aplicar padrões arquiteturais em frameworks para aplicações distribuídas

---
## Ementa

- Técnicas de serialização de dados
- APIs, exposição das funcionalidades do back-end através de serviços
- REST e verbos do HTTP
- Métodos de autenticação em aplicações distribuídas
- Padrões arquiteturais em frameworks para aplicações distribuídas voltadas a serviços
- Definição e exposição de serviços através de APIs
- Estudo de caso: integração com API externa e consumo de serviços via API
- Representação de recursos e serviços através do REST e técnicas correlatas
- Exposição de serviços no back-end e consumo na aplicação cliente
